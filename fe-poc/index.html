Asked and answered.

The four questions technical reviewers open with, answered straight from the spec.

Your provider key is encrypted with the Web Crypto API before it is written to Supabase, using a 32-byte master encryption key held only as a Deno Deploy environment variable. Decryption happens in memory at request time and is garbage-collected immediately. The UI only ever sees a masked tail like sk-proj-***789, and all logs are sanitized.

Text is split with a sliding window of 1,000 to 1,500 tokens and a 150-token overlap, sized so balance sheets and note tables are never cut horizontally. Each chunk is embedded with gemini-embedding-2 at a forced 768 dimensions and pushed to the HNSW index on Upstash Vector.

A daily cron hard-deletes chunks, vectors, and MinIO objects older than 7 days for non-admin tenants, and an hourly job cascades expired PRO (SIMULATE) accounts: files, vectors, counters, and tier. Storage quotas never reset, so this sweep is what keeps Supabase and Upstash inside their free tiers.

The first verified Investor webhook flips a global feature flag. From that moment PRO (REAL) becomes purchasable for every tenant. One sandbox invoice, Rp 1,440,000, opens the B2B tier for the whole platform. Try it in the Tiers section above.
